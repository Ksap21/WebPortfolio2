Homelab Infrastructure & Security Lab

Proxmox • Docker • Tailscale • Wazuh • Linux • Networking • Automation

01 Overview

My homelab is a self-hosted virtualization, networking, automation, and cybersecurity environment built around Proxmox VE.

The project provides a platform where I can deploy and manage virtual machines, Linux containers, Docker applications, secure remote networking, endpoint monitoring, local AI services, and security testing systems.

Rather than running every application directly on one operating system, the current architecture separates workloads across dedicated virtual machines and LXC containers.

04 Virtualization with Proxmox

Proxmox VE serves as the core virtualization platform for the lab. It allows multiple isolated systems to run on a single physical server while providing centralized control over virtual machines, containers, networking, storage, and resource allocation.

I use both full virtual machines and lightweight LXC containers. Security-focused operating systems run as VMs, while infrastructure services that require fewer resources are hosted in LXC containers.

07 Secure Remote Networking

Tailscale provides encrypted remote connectivity between authorized devices and the homelab.

A dedicated LXC container operates as a Tailscale subnet router. The router advertises the private homelab network and uses Linux IP forwarding to route authorized Tailnet traffic to internal resources.

Selected infrastructure systems also participate directly in the Tailscale network, providing another method of secure device-to-device communication.

09 Cybersecurity Testing Lab

The environment also contains a dedicated cybersecurity testing lab consisting of Kali Linux and Metasploitable2 virtual machines.

Metasploitable provides an intentionally vulnerable target while Kali Linux provides a separate security testing environment. This creates a controlled platform for learning offensive security, vulnerability assessment, Linux networking, and defensive concepts without targeting external systems.
